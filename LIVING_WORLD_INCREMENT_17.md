# Increment 17 — Remove narrative-only world progression
- Removed the timer-driven AI thread-summary mutation that fabricated generic business developments every 45 minutes.
- World events now need a durable business action, recorded task outcome, real-world signal, competitor move, meeting, communication or another explicit system event.
- Urgent calls can be triggered by a recently updated high-priority matter rather than a synthetic stage counter.
- Any completed evidence-backed task type may initiate a report-ready call; the message identifies the actual task type and saved document.
- The daily call cap counts every invite, preventing separate subsystems from bypassing the same limit.
