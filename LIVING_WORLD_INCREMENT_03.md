# Increment 03 — Employment and executed financial reviews
- Additive employment records; Chairman can appoint and terminate newly contracted employees, with contact creation, historical preservation, salary commitments, and task cancellation on termination. Existing leadership has no migrated contract yet. Candidate generation, interviews, payroll, autonomous hiring and succession remain pending.
- Explicit financial-review tasks execute automatically through the engine, using real journal balances, producing a persisted document and a completion record. General instructions are not automatically marked complete.
- The employee application and task type selector are integrated into the phone. Full authorization, information-sharing and payroll systems remain required.
- Deploy only to an isolated preview database after migration and tests. Test tenant isolation, appointment retries, former employee calls, task cancellation and actual report reconciliation.
